# Privacy and distribution review — v0.7.5

The current offline source distribution contains only public Markdown advice instructions, optional source references and platform adapter packages. No private coaching files, preference envelopes, hosted service source code, credentials or external database are bundled.

The Python validation suite checks generated archive contents, file paths, basic contact/credential patterns, source integrity and reproducibility. These static rules cannot establish that no narrative identifies an individual; human review is still necessary.

A previous public commit or release may remain cached or copied even after GitHub deletion. GitHub access controls do **not** deactivate the separately hosted former website: hosting administrators must unpublish it and verify that its endpoints are no longer available.

Do not claim verified native Claude or GitHub Copilot behavior without an actual installed-host test. Publication metadata and author/committer identity remain subject to human review.
